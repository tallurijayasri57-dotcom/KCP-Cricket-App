TITLE: KCP Cricket App - A Digital Transformation for Local Tournament Management

ABSTRACT:
The KCP Cricket App is a full-stack web application designed to solve the common problems faced by local cricket tournament organisers. For years, local tournaments have relied on manual methods like pen and paper to keep track of scores, team standings, and player statistics. This often leads to errors in point calculations, loss of data, and a lack of real-time visibility for players and fans.

To address these challenges, I built the KCP Cricket App—a robust digital platform that automates the entire process. The app allows organisers to manage teams, players, and match schedules through a modern, responsive interface. The backend is powered by Node.js and Express, ensuring fast and reliable communication between the user and the database. For data storage, I integrated Microsoft SQL Server (SSMS 19), which provides professional-grade security and data persistence.

The key highlight of the project is the automated Points Table, which calculates wins, losses, and Net Run Rate (NRR) in real-time as soon as a match result is updated. Additionally, the app features a premium 'Glassmorphism' UI, providing a high-end digital experience for a local sports community. This project demonstrates the power of digital transformation in simplifying complex manual workflows.
