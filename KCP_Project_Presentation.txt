PROJECT ABSTRACT

The KCP Cricket App is a web application created to easily manage local cricket tournaments. Normally, local matches use paper and pen for scoring, which leads to mistakes, arguments over points, and lost data. To fix this, we built a digital platform where we can manage teams, players, and live match scores easily.

We used HTML, CSS, and JavaScript for the frontend design to make it look very attractive and easy to use. For the backend, we used a Node.js server to handle all the requests. All the tournament data is safely stored in a Microsoft SQL Server (SSMS) database. A special feature in our app is that if the database connection fails for any reason, the app doesn't stop working; it temporarily saves data locally in a JSON file. Overall, our app takes local cricket matches to a professional level by removing paperwork and making scoring digital.
