% ---------------- SLIDE 2: Abstract ----------------
\begin{frame}{Project Abstract}
    \begin{itemize}
        \item The \textbf{KCP Cricket App} is a web application created to easily manage local cricket tournaments.
        \item Normally, local matches use paper and pen for scoring, which leads to mistakes and lost data.
        \item Our digital platform manages teams, players, and live match scores easily and professionally.
        \item We used HTML, CSS, JS, Node.js, and Microsoft SQL Server.
        \item It features a unique zero-downtime fallback mechanism (JSON storage) if the database fails.
    \end{itemize}
\end{frame}

% ---------------- SLIDE 3: Problem Statement ----------------
\begin{frame}{Why Did We Build This? (The Problem)}
    \begin{itemize}
        \item \textbf{Paper Scoring Issues:} Manual scoring on paper leads to mistakes and calculation errors.
        \item \textbf{Data Loss:} It is very hard to keep records of old matches and player statistics safely.
        \item \textbf{No Live Updates:} The audience outside the ground cannot see the live score.
        \item \textbf{Lack of Professionalism:} Local matches lack proper digital management.
    \end{itemize}
\end{frame}

% ---------------- SLIDE 4: Our Solution ----------------
\begin{frame}{Our Solution}
    \begin{itemize}
        \item \textbf{100\% Digital:} A completely paperless scoring system.
        \item \textbf{Live Tracking:} Real-time score updates for everyone tracking the match.
        \item \textbf{Auto Points Table:} The Leaderboard updates automatically based on who wins.
        \item \textbf{Safe Storage:} Saving all data permanently and securely in an SQL database.
    \end{itemize}
\end{frame}

% ---------------- SLIDE 5: Technologies Used ----------------
\begin{frame}{Technologies Used}
    \begin{itemize}
        \item \textbf{Frontend:} HTML5, CSS3, JavaScript.
        \item \textbf{Backend:} Node.js and Express.js.
        \item \textbf{Database:} Microsoft SQL Server (SSMS19).
        \item \textbf{Process:} Frontend $\rightarrow$ Node.js $\rightarrow$ SQL Database.
    \end{itemize}
\end{frame}

% ---------------- SLIDE 6: Main Features ----------------
\begin{frame}{Main Features of Our App}
    \begin{itemize}
        \item \textbf{Teams \& Players:} Easily add new teams and players to the tournament.
        \item \textbf{Live Match Board:} A simple and intuitive UI for ball-by-ball scoring.
        \item \textbf{Match Results:} Saving records of who won and who lost.
        \item \textbf{Leaderboard:} A points table that auto-calculates Net Run Rate and Points.
    \end{itemize}
\end{frame}

% ---------------- SLIDE 7: Database Connection & Safety ----------------
\begin{frame}{Database Connection \& Safety}
    \begin{itemize}
        \item \textbf{Connection:} Used the `mssql' package in Node.js to bridge the app and the database.
        \item \textbf{Security:} Used parameterized queries to stop hacking (SQL Injection).
        \item \textbf{Backup Plan:} If the SQL Server goes offline, the app saves data in a local `db.json' file so it never crashes.
    \end{itemize}
\end{frame}

        \item It completely stops manual mistakes and keeps tournament data safe forever.
        \item The application is fully ready to be deployed and used in real ground matches.
    \end{itemize}
\end{frame}
