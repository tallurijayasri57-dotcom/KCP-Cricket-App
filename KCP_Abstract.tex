\section*{Abstract}
{\fontsize{12}{15}\selectfont
Managing local cricket tournaments has traditionally been a manual and tedious process. Most organisers still rely on pen and paper or basic spreadsheets to track scores, maintain player records, and calculate points tables. This manual approach often leads to data inconsistency, delayed updates, and human errors in ranking calculations. 

The \textbf{KCP Cricket App} is a modern web-based solution designed to digitize the entire tournament lifecycle. Developed using a robust stack of \textbf{HTML, CSS, and JavaScript} for the frontend, and \textbf{Node.js with Express.js} for the backend, the application ensures a seamless and responsive user experience. To guarantee data persistence and reliability, the system is integrated with \textbf{Microsoft SQL Server (SSMS 19)}, providing a centralized database for all tournament-related information.

Key features of the application include:
\begin{itemize}
    \item \textbf{Dynamic Team and Player Management:} Organisers can easily add, edit, or remove teams and players with unique profiles and roles.
    \item \textbf{Live Match Scheduling:} An intuitive interface to schedule matches and track their status from 'Upcoming' to 'Finished'.
    \item \textbf{Automated Points Table:} A real-time leaderboard that automatically calculates Net Run Rate (NRR) and points based on match outcomes, eliminating manual calculations.
    \item \textbf{Glassmorphism UI Design:} A premium, dark-themed interface that provides a modern and engaging experience for users.
\end{itemize}

By replacing manual workflows with an automated digital system, the KCP Cricket App brings transparency, accuracy, and efficiency to local cricket tournament management.
