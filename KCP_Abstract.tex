\begin{abstract}
    \noindent The \textbf{KCP Cricket App} is a comprehensive web application developed to modernize and simplify the management of local cricket tournaments. Traditionally, local matches rely on manual paper-based scoring, which frequently leads to calculation errors, disputes, and the loss of historical data. To overcome these challenges, we built a fully digital platform that allows organizers to effortlessly manage teams, players, and live match scores. 
    
    \vspace{0.3cm}
    
    \noindent The frontend of the application is designed using HTML, CSS, and JavaScript, providing a highly attractive, intuitive, and responsive user interface. The backend is powered by a Node.js server that efficiently handles all API requests. For data security and persistence, all tournament records are securely stored in a Microsoft SQL Server (SSMS) database. A standout feature of our application is its fault-tolerant fallback mechanism: if the database connection drops, the app seamlessly shifts to local JSON storage, ensuring zero downtime and uninterrupted scoring. Overall, the KCP Cricket App elevates local cricket matches to a professional standard by eliminating paperwork and providing real-time digital scoring.
\end{abstract}
